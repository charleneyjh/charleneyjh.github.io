# Secret Garden source

Original editable Three.js garden, imported from the local playground.

From the repository root: `npm run garden:install` then `npm run build`.
Build output: `/secret-garden/` (ignored; generated by Vercel).
Only the two active Gaussian models are included; original local files remain untouched.
The homepage embeds the scene below About. Zoom buttons and drag-to-orbit are preserved; the wheel scrolls the portfolio page. Rendering pauses offscreen.
